# 水冷螺杆式冷水机组（单机）— 建模部件参数分析表

> 生成日期：2026-07-23
> 用户可修改参数：`外形尺寸长`(4700)、`外形尺寸宽`(1400)、`外形尺寸高`(1425)、`冷凝器管径`(75)、`蒸发器管径`(50)

---

## 联动派生变量速查

| 变量 | 公式 | 默认值 |
|------|------|--------|
| delta_w | 外形尺寸宽 - 1400 | 0 |
| delta_h | 外形尺寸高 - 1425 | 0 |
| L_main | (外形尺寸长 - 400 - 300) / 2 | 2000 |
| L_evap | 600 + 0.5 × delta_w | 600 |
| L_cond | 800 + 0.5 × delta_w | 800 |
| L_total_y | L_evap + L_cond | 1400 |
| H_evap | 1000 + delta_h | 1000 |
| H_cond | 1200 + delta_h | 1200 |

## 步骤1：水平支撑板

| 属性 | 详情 |
|------|------|
| **API** | `Box(baseOrigin, topOrigin, vectorX, vectorY, baseX, baseY, topX, topY)` |
| **截面形心** | `(0, 0, 25)` — YZ 平面，Z=T/2 |
| **截面尺寸** | Y向=**L_total_y**（1400），Z向=**50**（T，水平支撑板厚度） |
| **拉伸方向/距离** | 沿 **-X** 方向拉伸 **200**（T×4） |
| **镜像前平移** | `translate(0, -300-0.25×delta_w, 0)` |
| **镜像** | 步骤10：以 X=-L_main 面镜像到右侧 |
| **关联用户参数** | 截面Y向长度=**外形尺寸宽**（联动），厚度=常量50 |
| **固定常量** | 拉伸距离200, Z向尺寸50 |
| **可绑定参数建议** | 截面Y向 ← 外形尺寸宽（已联动） |
