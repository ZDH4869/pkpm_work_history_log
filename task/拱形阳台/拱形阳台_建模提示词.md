### 建模顺序

**全局坐标系说明：** 插入点为原点 (0,0,0)，XOY 面为水平面，Z 轴正向为竖直向上。所有尺寸单位 mm，角度使用弧度制。

#### 步骤1：支撑半圆柱体

| 属性 | 详情 |
|------|------|
| **API** | `Loft`（两截面放样） |
| **临时坐标系原点** | 全局原点 (0, 0, 0) |
| **截面定义** | 在 **XOY 面**，以原点为圆心，绘制半径为 **阳台半径 R = 阳台直径/2** 的半圆截面（上半圆弧 + 弦，弦沿 X 轴从 (-R, 0) 到 (R, 0)，圆弧在 +Y 半平面） |
| **截面构建方式** | `Section(Vec2(R, 0), scale(R) * Arc(pi), Vec2(-R, 0), Vec2(R, 0))` |
| **拉伸方向/距离** | 沿 **-Z** 方向拉伸 **阳台高度**：底面截面 `translate(0, 0, -阳台高度) * section`，顶面截面 `section`（Z=0） |
| **全局坐标范围** | Z ∈ [-阳台高度, 0]，X ∈ [-R, R]，Y ∈ [0, R] |

#### 步骤2：外延半圆环柱

| 属性 | 详情 |
|------|------|
| **API** | `Loft`（两截面放样）+ 截面布尔减 `-` |
| **临时坐标系原点** | 全局原点 (0, 0, 0) |
| **截面定义** | 在 **XOY 面**，以原点为圆心，外半径 R_outer = R + 0.5×阳台外延宽度，内半径 R_inner = R - 0.5×阳台外延宽度，分别绘制外半圆截面和内半圆截面，然后 `ring_sec = sec_outer - sec_inner` |
| **截面构建方式** | 外半圆：`Section(Vec2(R_outer, 0), scale(R_outer) * Arc(pi), Vec2(-R_outer, 0), Vec2(R_outer, 0))`；内半圆同理构造 |
| **拉伸方向/距离** | 沿 **+Z** 方向拉伸 **阳台外延高度**：底面截面 `ring_sec`（Z=0），顶面截面 `translate(0, 0, 阳台外延高度) * ring_sec` |
| **全局坐标范围** | Z ∈ [0, 阳台外延高度]，X ∈ [-R_outer, R_outer]，Y ∈ [0, R_outer] |

#### 步骤3：竖向主栏杆（Loft 圆形截面 + 环形阵列）

| 属性 | 详情 |
|------|------|
| **API** | `Loft`（两截面放样）+ `Array`（环形阵列） |
| **临时坐标系原点** | (0, 0, **阳台外延高度**)，记为 `Z_step3` |
| **截面定义** | 在 **XOY 面**（临时坐标），以 **(阳台半径, 0)** 为圆心，绘制半径为 **主栏杆截面宽度/2** 的**圆形截面** |
| **截面构建方式** | `half_main = 主栏杆截面宽度 / 2`；`vert_rail_sec = translate(rail_radius, 0, 0) * Section(scale(half_main) * Arc(2*pi))` |
| **拉伸方向/距离** | 沿 **+Z** 方向拉伸 **主栏杆高度**：底面 `translate(0, 0, Z_step3) * vert_rail_sec`，顶面 `translate(0, 0, Z_step3 + 主栏杆高度) * vert_rail_sec` |
| **阵列方式** | 以 Z 轴为旋转轴，从 0° 到 180°（含首尾），环形阵列 **竖向栏杆群阵列数量 N_main** 个。步长：若 N_main>1 则 `main_step = π/(N_main-1)`，否则 0 |
| **阵列构建方式** | `vert_rails_arr = Array(vertical_rail)`；`for i in range(N_main): arr.append(rotate(i * main_step))` |

#### 步骤4：下部水平栅格栏杆（Sweep 圆形截面沿半圆弧扫掠）

| 属性 | 详情 |
|------|------|
| **API** | `Sweep`（圆形截面沿半圆弧路径扫掠） |
| **临时坐标系原点** | (0, 0, **阳台外延高度**)，即 `Z_step3` |
| **截面定义** | 圆形截面，半径 = **栅格栏杆截面宽度/2**，截面形心全局坐标为 `(阳台半径, 0, Z_step3 + 水平栅格栏杆高度 + 栅格栏杆截面宽度/2)` |
| **截面构建方式** | `half_grid = 栅格栏杆截面宽度 / 2`；`z_center_lower = 水平栅格栏杆高度 + half_grid`；先创建 XOY 面的圆形截面，绕 X 轴旋转 -90° 使法线对齐圆弧轨迹，再平移至全局位置：`translate(rail_radius, 0, Z_step3 + z_center_lower) * rotate(Vec3(1,0,0), -0.5*pi) * Section(scale(half_grid) * Arc(2*pi))` |
| **扫掠路径** | 在 XOY 面，以原点为圆心、半径 1 的半圆弧 `Line(Arc(pi))`（截面已通过平移定位到 rail_radius 处） |
| **全局 Z 坐标** | 截面形心 Z = `Z_step3 + 水平栅格栏杆高度 + 栅格栏杆截面宽度/2` |

#### 步骤5：上部水平栅格栏杆（平移复制）

| 属性 | 详情 |
|------|------|
| **API** | `translate` 平移复制 |
| **构建方式** | 将步骤4的下部水平栅格栏杆沿 **+Z** 方向平移 **栅格栏杆高度 + 栅格栏杆截面宽度**：`translate(0, 0, 栅格栏杆高度 + 栅格栏杆截面宽度) * grid_rail_lower` |

#### 步骤6：环形主栏杆（Sweep 圆形截面沿半圆弧扫掠）

| 属性 | 详情 |
|------|------|
| **API** | `Sweep`（圆形截面沿半圆弧路径扫掠） |
| **临时坐标系原点** | (0, 0, **阳台外延高度**)，即 `Z_step3` |
| **截面定义** | 圆形截面，半径 = **主栏杆截面宽度/2**，截面形心全局坐标为 `(阳台半径, 0, Z_step3 + 主栏杆高度 - 主栏杆截面宽度/2)` |
| **截面构建方式** | `half_main = 主栏杆截面宽度 / 2`；`z_center_ring = 主栏杆高度 - half_main`；`translate(rail_radius, 0, Z_step3 + z_center_ring) * rotate(Vec3(1,0,0), -0.5*pi) * Section(scale(half_main) * Arc(2*pi))` |
| **扫掠路径** | 在 XOY 面，以原点为圆心、半径 1 的半圆弧 `Line(Arc(pi))`（与步骤4共用同一个 `arc_path` 变量） |
| **全局 Z 坐标** | 截面形心 Z = `Z_step3 + 主栏杆高度 - 主栏杆截面宽度/2` |

#### 步骤7：竖向栅格栏杆（Loft 圆形截面 + 交错环形阵列）

| 属性 | 详情 |
|------|------|
| **API** | `Loft`（两截面放样）+ `Array`（交错环形阵列） |
| **临时坐标系原点** | (0, 0, **阳台外延高度**)，即 `Z_step3` |
| **截面定义** | 在 **XOY 面**（临时坐标），以 **(阳台半径, 0)** 为圆心，绘制半径为 **栅格栏杆截面宽度/2** 的**圆形截面** |
| **截面构建方式** | `half_grid = 栅格栏杆截面宽度 / 2`；`vert_grid_sec = translate(rail_radius, 0, 0) * Section(scale(half_grid) * Arc(2*pi))` |
| **拉伸方向/距离** | 沿 **+Z** 方向拉伸，拉伸起点 Z = `Z_step3 + 水平栅格栏杆高度 + 栅格栏杆截面宽度/2`，拉伸终点 Z = 起点 Z + 栅格栏杆高度 + 栅格栏杆截面宽度 |
| **阵列方式** | 在每两个主栏杆之间的间隙内，交错放置 **栅格栏杆阵列数量 N_grid** 个。若 N_main>1 且 N_grid≥1：`gap_step = main_step`；对于每个间隙 i（0 到 N_main-2），`angle = i * gap_step + j * gap_step / (N_grid + 1)`（j 从 1 到 N_grid） |

| 属性 | 详情 |

| **圆柱体定义** | 起点 `Vec3(排水洞圆心X距离, 排水洞圆心Y距离, -阳台高度)`，终点 `Vec3(排水洞圆心X距离, 排水洞圆心Y距离, 0)`，两端半径均为 **排水洞直径/2** |
| **布尔运算** | 当 **是否需要排水洞 = '是'** 时执行 `support_combined - drain_hole`；否则不执行 |

#### 步骤9：支撑剪切半圆柱（挖空支撑体）

| 属性 | 详情 |
|------|------|
| **API** | `Loft`（两截面放样）+ 布尔减 `-` |
| **临时坐标系原点** | 全局原点 (0, 0, 0) |
| **截面定义** | 在 **XOY 面**，以原点为圆心，绘制半径为 **R_cut = (阳台直径 - 2×支撑板厚度)/2** 的半圆截面（与步骤1同结构，半径更小） |
| **截面构建方式** | `Section(Vec2(R_cut, 0), scale(R_cut) * Arc(pi), Vec2(-R_cut, 0), Vec2(R_cut, 0))` |
| **拉伸方向/距离** | 沿 **+Z** 方向拉伸 **阳台高度 - 支撑板厚度**：底面截面 `translate(0, 0, -阳台高度) * section`，顶面截面 `translate(0, 0, -支撑板厚度) * section` |
| **布尔运算** | `support_column + extend_ring - cut_cylinder`，即先将支撑柱和外延环合并，再减去内部剪切体，形成空心壳体 |

| **API** | `combine`（组合所有部件） |

| **栏杆 Y 向偏移** | 所有栏杆部件（步骤3-7）沿 **+Y** 方向统一平移 **0.5×主栏杆截面宽度**，使栏杆居中于支撑体边缘 |
| **组合部件清单** | `[support_combined, vert_rails_arr, grid_rail_lower, grid_rail_upper, ring_main_rail, vert_grid_arr]` |

### 关键技术要点

1. **必须强制加载的 Skills：**
   - `bimbase-pyp3d-modeling` — pyp3d 建模规范与 API 签名
   - `bimbase-modeling-agent-interaction` — 交互流程与代码模板
   - `bimbase-agent-geometry-rules` — 几何验证与 API 构建规则
   - `bimbase-pyp3d-function-reference` — 函数详细用法

2. **必须强制调用的 MCP：**
   - `get_summary_document()` — 了解可用 SDK
   - `get_skill_manifest()` — 获取结构化 symbol 索引
   - `get_skill_bundle(["Section", "Loft", "Sweep", "Cone", "Arc", "Bool", "Combine"])` — 批量获取所需 API 文档（自动带编码规范）

3. **关键 API 使用注意事项：**
   - **Section**：仅接受 Vec2 和二维 Line/Arc，禁止混入 Vec3
   - **Loft**：截面 ≥2 个，空间分离（不能共面），截面方向/开闭/分段必须一致
   - **Sweep**：截面必须旋转使法线对齐轨迹方向（绕 X 轴旋转 -90°），轨迹仅单段直线或圆弧
   - **Cone**：两端半径相等时为圆柱体
   - **Array**：需要先创建 `Array(geometry)` 对象，再通过 `append(rotate(angle))` 添加旋转副本
   - **布尔运算**：`a - b` 布尔减、`a + b` 布尔并（合并），布尔运算后颜色被抹除
   - **combine**：组合多个几何体，不做布尔融合，保留各自属性

4. **变换顺序**：从右到左执行，`translate * rotate * scale * geometry`

5. **截面法线对齐规则（Sweep 关键）**：
   - 截面默认在 XOY 面，法线沿 Z 轴
   - 圆弧扫掠路径在 XOY 面，轨迹切线在 XOY 面内
   - 需要将截面绕 X 轴旋转 -90°（`rotate(Vec3(1,0,0), -0.5*pi)`），使截面法线从 Z 轴翻转到 Y 轴，从而对齐圆弧的切线方向

6. **圆形截面构建方式**：所有栏杆截面均使用圆形截面 `Section(scale(radius) * Arc(2*pi))`，而非方形截面

### 补充说明

1. **半圆截面的方向**：`Arc(pi)` 从 (1,0,0) 出发逆时针画半圆到达 (-1,0,0)，即圆弧在 +Y 半平面。Section 的四个元素依次为：起点 (R,0) → 半圆弧 → 终点 (-R,0) → 弦闭合回 (R,0)。

2. **栏杆的 Y 向偏移**：所有栏杆部件在最后统一沿 +Y 平移 `0.5 * 主栏杆截面宽度`，确保栏杆居中于支撑半圆柱体边缘，而不是骑在边缘上。

3. **排水洞位置**：排水洞圆心在 XOY 面的坐标为 (排水洞圆心X距离, 排水洞圆心Y距离)，Z 方向从 -阳台高度 到 0（贯穿整个支撑体）。

4. **栅格栏杆交错排列**：竖向栅格栏杆不放置在主栏杆所在的角度位置，而是放置在每两个相邻主栏杆之间的间隙中，形成交错排列效果。

5. **支撑板厚度（空心壳体）**：通过布尔减实现——先用阳台直径创建实心半圆柱，再用 `(阳台直径 - 2×支撑板厚度)` 创建内部半圆柱并减去，形成厚度为支撑板厚度的空心壳体。内部剪切体只从 Z=-阳台高度 拉伸到 Z=-支撑板厚度（底部保留完整厚度）。

6. **支撑体布尔组装顺序**：必须先将支撑柱和外延环合并（`support_column + extend_ring`），再减去内部剪切体（`- cut_cylinder`），最后根据需要减去排水洞（`- drain_hole`）。
