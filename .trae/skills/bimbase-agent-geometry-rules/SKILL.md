# BIMBase Agent 几何理解与验证规则

> **冲突优先级规则（最高优先级，必须遵守）**
> 1. **建模技术要求**：本地 skills/markdown 内容若与 `BIMBaseAI2PY_MCPServer` 获取到的建模技术要求（函数签名、参数语义、几何定位语义、编码规范等）发生冲突或解释不同，**以 `BIMBaseAI2PY_MCPServer` 为第一执行准则**。

> 面向 AI Agent：规定建模推理规则、强制验证流程、常见错误预防，确保精确建模。

## 一、建模前强制流程（每次必须执行，不可跳过）

### 1.1 强制加载 Skills & MCP & 知识库

每次 BIMBase 建模任务开始时，Agent 必须按顺序执行以下加载：

```
1. 调用 Skill: bimbase-pyp3d-modeling        → 加载 SKILL.md（API 签名、标准结构、变换规则）
2. 调用 Skill: bimbase-modeling-agent-interaction → 加载交互规范（信息收集、提问模板）
3. 调用 BIMBaseAI2PY_MCPServer: get_summary_document() → 首次建模必调，了解全部可用 SDK
4. 调用 BIMBaseAI2PY_MCPServer: get_skill_manifest()   → 获取结构化 symbol 索引
5. 调用 BIMBaseAI2PY_MCPServer: get_skill_bundle(["所需API"]) → 批量获取 API 文档（自动附带编码规范）
6. 读取: BIMBase_AIAgent_建模指南.md           → 完整技术参考
7. 读取: BIMBase_pyp3d_建模方法函数大全.md      → 函数详细用法
8. 读取: BIMBase_几何建模精确交互规范.md        → 用户交互规范
```

> **缓存策略**：Agent 可在同一次会话中缓存已加载的 Skills/MCP 内容，避免重复消耗上下文。但当用户切换建模任务（新文件）时，应重新确认 API 签名。

### 1.2 生成"建模参数确认表"（代码生成前必须输出）

在生成任何 Python 代码之前，Agent 必须解析用户需求，生成以下表格供用户确认：

| 步骤 | 部件 | API | 临时坐标系原点 | 截面/轴线定义 | 拉伸方向/距离 | 全局坐标范围 |
|------|------|-----|-------------|-------------|-------------|------------|
| 1 | 部件名 | 函数名 | 坐标(全局) | 形心/起点/终点 | 方向±距离 | 全局 min→max |
| 2 | ... | ... | ... | ... | ... | ... |

**表格要求：**
- 每个步骤独立一行
- 临时坐标系原点注明是全局坐标还是相对坐标
- 截面定义必须明确：形心/起点/终点、尺寸、所在平面
- 全局坐标范围用 `x∈[min,max], y∈[min,max], z∈[min,max]` 或 `(x,y,z)→(x,y,z)` 格式
- 布尔运算部件需单独列出被减体和减体

**用户确认后再生成代码。** 确认方式：回复"确认"或指出需要修正的项。

**示例：**

## 二、关键 API 构建规则

### 2.1 Box —— 四棱台/长方体

> ⚠️ **Box 无本地 `.py` 参考，函数签名与定位语义必须以 `BIMBaseAI2PY_MCPServer` 官方 SDK 文档为准。** 使用前必须调用 `get_skill_doc("Box")`。

**官方已确认的核心语义（以 MCP 查询结果为准）：**
- `baseOrigin` / `topOrigin` 是底面/顶面的**角点**（非截面中心），实体沿 `+vectorX`/`+vectorY` 正方向铺开。
- 上下截面锚定同一个角：顶底尺寸不同时缩向锚定角（单边收分），**非居中收分**。

**空心箱体（内外箱体形心重合）推荐改用 `Section + Loft`**（形心定位，见函数大全 4.2 节）：
- 内外箱体截面均以**形心在原点**定义（`translate(-L/2, -W/2, 0) * Section(...)`），内外形心天然重合，无需计算角点偏移。
- 内箱体尺寸：`baseX_inner = baseX_outer - 2×T`、`baseY_inner = baseY_outer - 2×T`。
- 布尔减：`外箱体 Loft - 内箱体 Loft`。

### 2.2 Cone —— 圆柱/圆台

```python
Cone(centerA, centerB, radiusA, radiusB)
```

| 规则 | 说明 |
|------|------|
| 两端圆心 | centerA 和 centerB 是全局坐标下的 Vec3 点 |
| 圆柱 | radiusA == radiusB 时为圆柱体 |
| 方向 | centerA → centerB 为拉伸方向 |

### 2.3 Sweep —— 扫掠

```python
Sweep(section, path)
```

| 规则 | 说明 |
|------|------|
| 路径 | 多段线各段首尾相连，**不闭合**（除非明确要求闭合） |
| 截面 | 开口截面，N 个顶点顺序定义，**不添加闭合点** |
| 法线 | 截面法线必须旋转对齐首段路径方向 |
| 路径坐标系 | 路径点坐标必须先转为全局坐标，再构建 Line |

**错误示例（曾导致把手构建失败）：**
```python
# ❌ 正方形截面添加了第5个闭合点
vertices = [Vec2(-half, -half), Vec2(half, -half), Vec2(half, half), Vec2(-half, half), Vec2(-half, -half)]
```

**正确做法：**
```python
# ✅ 正方形截面4个顶点，不闭合
vertices = [Vec2(-half, -half), Vec2(half, -half), Vec2(half, half), Vec2(-half, half)]
```

### 2.4 Section —— 截面

| 规则 | 说明 |
|------|------|
| 元素类型 | 仅接受 Vec2 / 二维 Line / 二维 Arc |
| 禁止 | 禁止混入 Vec3 |
| 默认位置 | 位于 XOY 平面 |

### 2.5 布尔运算

| 规则 | 说明 |
|------|------|
| 验证 | 生成后必须输出被减体和减体的全局坐标范围，验证厚度正确 |
| 颜色 | 布尔运算后颜色被抹除，需重设 |

## 三、临时坐标系处理规则

```
规则1：当用户声明"以 P 点为临时坐标系原点"后，该段落内所有坐标均为相对 P 的坐标。
规则2：临时坐标系仅平移，不旋转。XYZ 轴方向与原坐标系一致。
规则3：新段落重新声明 → 切换新临时坐标系。
规则4：未声明 → 全局坐标系。
规则5：实现时，先计算 P 在全局坐标中的位置，再将段落内所有相对坐标叠加 P 得到全局坐标。
```

## 四、主动复盘规则（触发条件：≥2 次同类修改）

**当用户对同一问题或相似问题进行 ≥2 次代码修改时，Agent 必须：**

1. **暂停修改**，不再继续尝试
2. **复盘分析**：列出当前所有不确定的坐标起点/终点/截面原点/拉伸方向
3. **向用户提问**：以表格形式列出"我当前理解的位置" vs "请确认是否正确"

**复盘提问模板：**

> 我当前理解的关键坐标如下，请确认是否正确：
>
> | 假设项 | 我当前的理解 | 全局坐标（默认值） | 是否正确？ |
> |--------|-------------|------------------|-----------|
> | 控水箱临时坐标系原点 | (0, cy, cz) | (0, -426.78, -176.78) | ？ |
> | 矩形截面 Y 起点 | -25（形心=临时原点） | -451.78 | ？ |
> | 矩形截面 Z 起点 | -25（形心=临时原点） | -201.78 | ？ |
> | 出水管顶面圆心 | (box_half, 0, box_y/2) 在临时坐标下 | (100, -426.78, -151.78) | ？ |
> | 出水管拉伸方向 | 沿 -Z | 终点 Z = -251.78 | ？ |

## 六、特征点规则

### 6.1 SnapMode 完整枚举

```python
class SnapMode(Enum):
    Invalid              = -1           # 非法值
    First                = 0            # 初始化
    Nearest              = 1            # 最近点
    MidPoint             = 1 << 2       # 中点
    Center               = 1 << 3       # 中心点
    EndPoint             = 1 << 4       # 端点
    Intersection         = 1 << 6       # 交点
    Tangency             = 1 << 7       # 相切
    TangentPoint         = 1 << 8       # 相切点
    Perpendicular        = 1 << 9       # 垂直
    PerpendicularPoint   = 1 << 10      # 垂直点
    Parallel             = 1 << 11      # 平行
    Multi3               = 1 << 12
    Multi1               = 1 << 14
    Multi2               = 1 << 15
    GeometricCenter      = 1 << 16      # 几何中心点
    Quadrant             = 1 << 17      # 象限点
    Extension            = 1 << 18      # 延伸线
    ApparentIntersection = 1 << 19      # 外观交点
    Insertion            = 1 << 20      # 插入点
    Node                 = 1 << 21      # 节点
    enGetBaseCurve       = 1 << 22      # 基准线
```

### 6.2 SnapMode 选择规则（核心规则）

| 特征点位置 | 应使用的 SnapMode | 说明 |
|-----------|-------------------|------|
| 截面圆心 | `GeometricCenter` | Cone 的 centerA/centerB 截面圆心 |
| 拉伸体轴线终点 | `GeometricCenter` | 圆柱/圆台/棱柱的轴线两端截面形心 |
| 拉伸体轴线中点 | `GeometricCenter` | 圆柱/圆台/棱柱的轴线中点 |
| 几何体表面形心 | `GeometricCenter` | Box 的 baseOrigin/topOrigin、Cube 面心 |
| 几何体体心 | `GeometricCenter` | Cube/Sphere 的几何中心 |
| 长方体/棱柱顶点 | `EndPoint` | 几何体的明确角点 |
| 线段端点 | `EndPoint` | Line 的起点/终点 |

> **核心原则：绝大多数情况默认使用 `SnapMode.GeometricCenter`。** 只有当特征点明确是几何体的角点/顶点等非中心位置时，才使用 `SnapMode.EndPoint`。

### 6.3 特征点确认流程（代码生成前强制执行）

**在编写或修改 Python 代码之前，Agent 必须与用户确认每个特征点的位置和 SnapMode 类型：**

1. 列出所有计划定义的特征点，以表格形式呈现：

| 特征点名称 | 位置描述 | 建议 SnapMode | 是否正确？ |
|-----------|---------|--------------|-----------|
| 入水管顶部 | 入水管上端截面圆心 | `GeometricCenter` | ？ |
| 中心出水管底部 | 中心出水管下端截面圆心 | `GeometricCenter` | ？ |
| 配电口 | 水箱表面某点 | `GeometricCenter` | ？ |

2. 用户确认后方可编写代码。

3. 若用户未明确指定 SnapMode，Agent 默认使用 `GeometricCenter` 并在确认表中标注。

### 6.4 驱动点表达式规则

| 规则 | 说明 |
|------|------|
| 参数可见性 | 驱动点引用的 Attr 必须 `obvious=True`（隐藏参数导致解析失败） |
| 表达式格式 | 三轴表达式必须含 `[定位点X/Y/Z]` |
| 只读参数 | 若参数用户不应修改，加 `readonly=True` 置灰 |
| 数学运算 | `*` `/` `()` `**` 等无限制 |

## 七、参数绑定规则

| 类型 | 实现方式 | 示例 | 适用场景 |
|------|---------|------|---------|
| 计算绑定 | 在 `replace()` 中动态计算 | `disp_L = L / 3.0` | 相对尺寸随主尺寸联动 |
| 静态默认值 | `Attr(100.0, obvious=True)` | `self['显示屏长度'] = Attr(100.0)` | 用户可独立调整 |
| 厚度绑定 | 直接使用主参数 | `display_Y = T` | 部件厚度=水箱厚度 |
