# BIMBase 几何建模精确交互规范

> **冲突优先级规则（最高优先级，必须遵守）**
> 1. **建模技术要求**：本地 skills/markdown 内容若与 `BIMBaseAI2PY_MCPServer` 获取到的建模技术要求（函数签名、参数语义、几何定位语义、编码规范等）发生冲突或解释不同，**以 `BIMBaseAI2PY_MCPServer` 为第一执行准则**。
> 2. **个人建模喜好**：涉及个人建模喜好（建模定位提示词喜好、特殊模型部件调用，如散热片、半椭球体等）时，**以本地 skills/markdown 为第一执行准则**。

> 面向用户：指导如何编写精确的建模提示词，消除 Agent 理解歧义，实现一次对话完成几何体构建。
> 编制日期：2026-07-15

## 〇、输入形式与复杂度确认（建模前）

用户既可以输入**图片**（参考尺寸图）也可以输入**文字提示词**，二者往往是笼统概括的描述。Agent 在建模前必须完成以下对齐：

1. **部件理解对齐（盘问式，参考 grill-me 逻辑）**
   - 图片输入：Agent 先做**图片解析**，识别目标模型由哪些部件组成；文字输入：先拆解出部件清单。
   - 对图片/文字中**识别不清楚**的部件，主动、逐个盘问确认，直到双方对"模型由哪些部件、每个部件是什么"达成一致，剔除冗余与错误信息干扰。

2. **建模精细/复杂程度确认（是否简化）**
   - 在输出「建模参数确认表」之前，确认各部件建模的精细/复杂程度。
   - Agent 需**给出具体简化方案描述供用户选择**（如栏杆：A.立柱+双横杆 B.仅双横杆 C.不建），而非只问"要不要简化"。
   - **例外**：用户明确要求"复刻 / 按图片尺寸 / 按建模提示词建模"时，跳过复杂度确认，直接按完整精细度理解。

### 图片识别结果汇报模板（图片解析后必输出）

Agent 完成图片解析后，按以下 6 段固定结构整理汇报给用户确认：

1. **总体信息**：模型类型 + 关键总体尺寸/参数
2. **尺寸表格**：把图中截面/尺寸表整理成 markdown 表格
3. **建模部件清单**：可辨识部件逐条列出
4. **尺寸信息**：图中代号/局部尺寸
5. **属性业务信息**：模型名称、各部件名称、材质/型号等业务属性（对应 Attr 的"专业属性"分组）
6. **疑惑点列表**：图片识别不清楚、无法确认的部分，单独列出请用户裁定

### 复杂度确认话术（汇报后必做）

1. **建模范围（多选）**：列出所有可辨识部件，让用户勾选要建模的部件
2. **各部件精细度**：给出 2~4 档简化方案（例：栏杆 → A.立柱+双横杆 / B.仅双横杆 / C.不建）
3. **缺失尺寸处理**：图中未标注的尺寸给出可调默认值

### 结构化提问话术模板

| 要素 | 说明 | 示例 |
|------|------|------|
| header | 简短标题 | "筒壁型号" |
| question | 具体问题 | "默认按哪个筒壁型号建模？" |
| options | 2~4 个选项，每项 label + description | "TB60/2.0（囱口内径 2.0m，中间型号，推荐）" |
| multiSelect | 多选题设 true | "建模范围包含哪些部件？" |

要求：一次集中问清；选项 description 说明推荐理由；关键尺寸/数量/朝向/是否参数化不靠猜。

## 一、三段式建模流程

### 第一阶段：几何体构建（目标：1次对话）

**用户必须提供的信息：**

| 序号 | 信息类型 | 精确描述示例 | 模糊描述（应避免） |
|------|---------|-------------|------------------|
| 1 | 插入点 | "插入点为 (0,0,0)" | 省略 |
| 2 | 临时坐标系原点 | "以 (0, cy, cz) 为临时坐标原点" | 省略 |
| 3 | 截面原点定位 | "矩形截面 Y轴长50（起点-25，终点+25），形心位于临时坐标原点" | "矩形截面 50×50" |
| 4 | 截面绘制平面 | "在 zoy 面绘制" | 省略 |
| 5 | 拉伸方向与距离 | "沿 X 轴正向和负向各拉伸 100" | "拉伸 200" |
| 6 | 部件间空间关系 | "出水管顶面圆心固定在控水箱底面，X坐标=±box_half" | "出水管在控水箱底部" |
| 7 | 布尔运算 | "外箱体减去内箱体，内箱体截面形心与外箱体重合" | "空心水箱" |

**Agent 必须做的事：**
1. 强制调用 MCP + Skills 验证 API 签名
2. 生成"建模参数确认表"（见下文模板）供用户确认
3. 用户确认后再生成 Python 代码
4. 截面原点不明确时，立即提问，不猜测

### 第二阶段：参数化与特征点（目标：1次对话）

**用户需提供：**
- 参数名称、默认值、面板属性（obvious/readonly/combo）
- 特征点位置（用临时坐标系或相对矢量描述）
- 参数绑定关系（计算绑定 vs 静态默认值）

**Agent 需做：**
- 将第一阶段硬编码数值替换为 Attr 参数
- 设置 obvious/readonly/combo/show 属性
- 定义驱动点表达式（注意：引用参数必须 obvious=True）

**特征点 SnapMode 选择规则（核心规则）：**
- 截面圆心、拉伸体轴线终点/中点、几何体表面形心、几何体体心 → 一律使用 `SnapMode.GeometricCenter`
- 几何体角点/顶点 → 使用 `SnapMode.EndPoint`
- **绝大多数情况默认使用 `SnapMode.GeometricCenter`**

**特征点确认流程（代码生成前强制执行）：**
Agent 必须在生成代码前，以表格形式与用户确认每个特征点的位置和 SnapMode 类型：

| 特征点名称 | 位置描述 | 建议 SnapMode | 是否正确？ |
|-----------|---------|--------------|-----------|
| 储热罐顶部圆心 | 储热罐顶面截面圆心 | `GeometricCenter` | ？ |
| 底部水管终点 | 底部水管远端截面圆心 | `GeometricCenter` | ？ |
| 左侧入水管顶部圆心 | 左侧入水管上端截面圆心 | `GeometricCenter` | ？ |

用户确认后方可编写代码。若用户未明确指定 SnapMode，Agent 默认使用 `GeometricCenter` 并在确认表中标注。

### 第三阶段：精细化微调（目标：1次对话）

**用户可调整：**
- 默认参数值
- 新增/删除部件
- 部件间相对位置微调
- 颜色、透明度等

## 二、精确描述模板

### 2.1 矩形截面

```
✅ 正确：在 zoy 面绘制矩形截面，Y轴长度 50（起点 -25，终点 +25），Z轴长度 50（起点 -25，终点 +25），形心位于临时坐标原点
❌ 错误：矩形截面 50×50
```

**关键要素：** 平面 + 尺寸 + 起点/终点 + 形心位置

### 2.2 圆形截面

```
✅ 正确：在 xoy 面，以 (100, 0, 25) 为圆心，半径 10，沿 -Z 拉伸 100 形成圆柱体
❌ 错误：在底部画一个水管
```

**关键要素：** 平面 + 圆心坐标 + 半径 + 拉伸方向 + 拉伸距离

### 2.3 多段线扫掠路径

```
✅ 正确：4 点依次连接，不闭合：(0,0,0) → (0,0,-2) → (0,-2,-4) → (0,-2,-14)，沿路径扫掠边长为 2 的正方形截面
❌ 错误：绘制一条折线
```

**关键要素：** 点数 + 坐标序列 + 是否闭合 + 截面形状与尺寸

### 2.4 空心长方体（布尔减法）

```
✅ 正确：外箱体 Box 截面形心 (0,0,H/2)，尺寸 L×W×H；内箱体截面形心与外箱体重合，尺寸 (L-2T)×(W-2T)×(H-2T)；外箱体 - 内箱体
❌ 错误：空心水箱
```

**关键要素：** 外箱体形心 + 外箱体尺寸 + 内箱体形心（必须与外箱体重合）+ 内箱体尺寸计算 + 布尔运算

### 2.5 部件空间关系

```
✅ 正确：入水管底部截面圆心与水箱顶板上表面形心重合，入水管轴线与螺栓a轴线重合
❌ 错误：入水管在水箱顶部
```

**关键要素：** 用"重合/接触/偏移"等拓扑关系，辅以坐标

## 三、常见歧义速查表

| 模糊描述 | 歧义点 | 应确认的问题 |
|---------|--------|------------|
| "矩形截面 50×50" | 起点在哪？ | 起点是 (-25,-25) 还是 (0,0)？形心在临时原点吗？ |
| "沿 Z 轴拉伸" | 正向还是负向？ | 沿 +Z 还是 -Z 拉伸？ |
| "前板" / "正视图" | 哪个方向？ | 前表面 = yoz 面中 X 数值最大的面？ |
| "底板" / "底部" | 哪个方向？ | 底面 = xoy 面中 Z 值最小的面？ |
| "折线路径" | 几个点？闭合吗？ | 几个点？坐标序列？首尾闭合吗？ |
| "左右两侧" | 沿哪个轴对称？ | 沿 X 轴还是 Y 轴对称？ |
| "空心长方体" | 壁厚怎么算？ | 厚度从外表面向内偏移？内外形心重合吗？ |
| "拉伸 200" | 单向还是双向？ | 沿正方向 200，还是正负各 100？ |
| "临时坐标系原点" | 生效范围？ | 后续哪些坐标是相对此原点的？ |

## 五、临时坐标系完整规则

> 1. 当用户说"**以某点为临时坐标系原点**"后，该段落中后续所有坐标参数和数值描述均以该临时坐标系原点为基准（即相对坐标），除非用户明确说明是原始坐标系参数。
> 2. 临时坐标系**仅做原点平移**，X/Y/Z 轴方向及各平面（xoy、zoy、zox 等）均与原始坐标系保持平行，不涉及任何旋转。
> 3. 若用户在新的段落中**重新声明**"以某点为临时坐标系原点"，则后续坐标切换为新的临时坐标系。
> 4. 若用户**未提及任何临时坐标系**，默认所有坐标均为原始坐标系（全局坐标系）下的绝对坐标。
> 5. 代码实现时，先计算临时坐标系原点在全局坐标中的位置，再将段落内所有相对坐标叠加该原点偏移得到全局坐标。

## 六、方向约定

> **核心规则**："前 / 右 / 顶" = 坐标轴最大值面；"后 / 左 / 底" = 坐标轴最小值面。

| 术语 | 含义 |
|------|------|
| 正视图 / 前表面 | yoz 面中 X 数值最大的面（+X） |
| 后表面 | yoz 面中 X 数值最小的面（-X） |
| 右视图 / 右侧面 | xoz 面中 Y 数值最大的面（+Y） |
| 左侧面 | xoz 面中 Y 数值最小的面（-Y） |
| 顶面 | xoy 面中 Z 数值最大的面（+Z） |
| 底面 | xoy 面中 Z 数值最小的面（-Z） |

### 角点命名规则

站在该面外侧、面向该面观察，"左 / 右 / 上 / 下"按观察者视角定义：

| 面 | 左 | 右 | 上 | 下 |
|----|----|----|----|----|
| 前表面（yoz 面，X 最大） | Y 最小 | Y 最大 | Z 最大 | Z 最小 |
| 右侧面（xoz 面，Y 最大） | X 最大 | X 最小 | Z 最大 | Z 最小 |

| 角点 | 坐标构成 |
|------|---------|
| 前表面左下角 | X最大、Y最小、Z最小 |
| 前表面左上角 | X最大、Y最小、Z最大 |
| 前表面右下角 | X最大、Y最大、Z最小 |
| 前表面右上角 | X最大、Y最大、Z最大 |
| 右侧面左下角 | Y最大、X最大、Z最小 |
| 右侧面左上角 | Y最大、X最大、Z最大 |
| 右侧面右下角 | Y最大、X最小、Z最小 |
| 右侧面右上角 | Y最大、X最小、Z最大 |
