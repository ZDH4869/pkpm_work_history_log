# BIMBase 几何建模精确交互规范

> **冲突优先级规则（最高优先级，必须遵守）**
> 1. **建模技术要求**：本地 skills/markdown 内容若与 `BIMBaseAI2PY_MCPServer` 获取到的建模技术要求（函数签名、参数语义、几何定位语义、编码规范等）发生冲突或解释不同，**以 `BIMBaseAI2PY_MCPServer` 为第一执行准则**。
> 2. **个人建模喜好**：涉及个人建模喜好（建模定位提示词喜好、特殊模型部件调用，如散热片、半椭球体等）时，**以本地 skills/markdown 为第一执行准则**。

> 面向用户：指导如何编写精确的建模提示词，消除 Agent 理解歧义，实现一次对话完成几何体构建。

## 一、三段式建模流程

### 第一阶段：几何体构建（目标：1次对话）

**用户必须提供的信息：**

| 序号 | 信息类型 | 精确描述示例 | 模糊描述（应避免） |
|------|---------|-------------|------------------|
| 1 | 插入点 | "插入点为 (0,0,0)" | 省略 |
| 2 | 临时坐标系原点 | "以 (0, cy, cz) 为临时坐标原点" | 省略 |
| 3 | 截面原点定位 | "矩形截面 Y轴长50（起点-25，终点+25），形心位于临时坐标原点" | "矩形截面 50×50" |
| 4 | 截面绘制平面 | "在 zoy 面绘制" | 省略 |
| 5 | 拉伸方向与距离 | "沿 X 轴正向和负向各拉伸 100" | "拉伸 200" |
| 6 | 部件间空间关系 | "出水管顶面圆心固定在控水箱底面，X坐标=±box_half" | "出水管在控水箱底部" |
| 7 | 布尔运算 | "外箱体减去内箱体，内箱体截面形心与外箱体重合" | "空心水箱" |

**Agent 必须做的事：**
1. 强制调用 MCP + Skills 验证 API 签名
2. 生成"建模参数确认表"（见下文模板）供用户确认
3. 用户确认后再生成 Python 代码
4. 截面原点不明确时，立即提问，不猜测

### 第二阶段：参数化与特征点（目标：1次对话）

**用户需提供：**
- 参数名称、默认值、面板属性（obvious/readonly/combo）
- 特征点位置（用临时坐标系或相对矢量描述）
- 参数绑定关系（计算绑定 vs 静态默认值）

**Agent 需做：**
- 将第一阶段硬编码数值替换为 Attr 参数
- 设置 obvious/readonly/combo/show 属性
- 定义驱动点表达式（注意：引用参数必须 obvious=True）

### 第三阶段：精细化微调（目标：1次对话）

**用户可调整：**
- 默认参数值
- 新增/删除部件
- 部件间相对位置微调
- 颜色、透明度等

## 二、精确描述模板

### 2.1 矩形截面

```
✅ 正确：在 zoy 面绘制矩形截面，Y轴长度 50（起点 -25，终点 +25），Z轴长度 50（起点 -25，终点 +25），形心位于临时坐标原点
❌ 错误：矩形截面 50×50
```

**关键要素：** 平面 + 尺寸 + 起点/终点 + 形心位置

### 2.2 圆形截面

```
✅ 正确：在 xoy 面，以 (100, 0, 25) 为圆心，半径 10，沿 -Z 拉伸 100 形成圆柱体
❌ 错误：在底部画一个水管
```

**关键要素：** 平面 + 圆心坐标 + 半径 + 拉伸方向 + 拉伸距离

### 2.3 多段线扫掠路径

```
✅ 正确：4 点依次连接，不闭合：(0,0,0) → (0,0,-2) → (0,-2,-4) → (0,-2,-14)，沿路径扫掠边长为 2 的正方形截面
❌ 错误：绘制一条折线
```

**关键要素：** 点数 + 坐标序列 + 是否闭合 + 截面形状与尺寸

### 2.4 空心长方体（布尔减法）

```
✅ 正确：外箱体 Box 截面形心 (0,0,H/2)，尺寸 L×W×H；内箱体截面形心与外箱体重合，尺寸 (L-2T)×(W-2T)×(H-2T)；外箱体 - 内箱体
❌ 错误：空心水箱
```

**关键要素：** 外箱体形心 + 外箱体尺寸 + 内箱体形心（必须与外箱体重合）+ 内箱体尺寸计算 + 布尔运算

### 2.5 部件空间关系

```
✅ 正确：入水管底部截面圆心与水箱顶板上表面形心重合，入水管轴线与螺栓a轴线重合
❌ 错误：入水管在水箱顶部
```

**关键要素：** 用"重合/接触/偏移"等拓扑关系，辅以坐标

## 三、常见歧义速查表

| 模糊描述 | 歧义点 | 应确认的问题 |
|---------|--------|------------|
| "矩形截面 50×50" | 起点在哪？ | 起点是 (-25,-25) 还是 (0,0)？形心在临时原点吗？ |
| "沿 Z 轴拉伸" | 正向还是负向？ | 沿 +Z 还是 -Z 拉伸？ |
| "前板" | 哪个方向？ | 前板 = 沿 Y 轴正向第一块板？ |
| "底板" / "底部" | 哪个方向？ | 底板 = 沿 Z 轴正向第一块板（Z 值最小的面）？ |
| "折线路径" | 几个点？闭合吗？ | 几个点？坐标序列？首尾闭合吗？ |
| "左右两侧" | 沿哪个轴对称？ | 沿 X 轴还是 Y 轴对称？ |
| "空心长方体" | 壁厚怎么算？ | 厚度从外表面向内偏移？内外形心重合吗？ |
| "拉伸 200" | 单向还是双向？ | 沿正方向 200，还是正负各 100？ |
| "临时坐标系原点" | 生效范围？ | 后续哪些坐标是相对此原点的？ |

## 五、临时坐标系完整规则

> 1. 当用户说"**以某点为临时坐标系原点**"后，该段落中后续所有坐标参数和数值描述均以该临时坐标系原点为基准（即相对坐标），除非用户明确说明是原始坐标系参数。
> 2. 临时坐标系**仅做原点平移**，X/Y/Z 轴方向及各平面（xoy、zoy、zox 等）均与原始坐标系保持平行，不涉及任何旋转。
> 3. 若用户在新的段落中**重新声明**"以某点为临时坐标系原点"，则后续坐标切换为新的临时坐标系。
> 4. 若用户**未提及任何临时坐标系**，默认所有坐标均为原始坐标系（全局坐标系）下的绝对坐标。
> 5. 代码实现时，先计算临时坐标系原点在全局坐标中的位置，再将段落内所有相对坐标叠加该原点偏移得到全局坐标。

## 六、方向约定

| 术语 | 含义 |
|------|------|
| 前板 | 沿 Y 轴正向第一块板 |
| 背板 | 沿 Y 轴负向第一块板 |
| 底板（Z 最小面） | 沿 Z 轴正向第一块板 |
| 顶板（Z 最大面） | 沿 Z 轴负向第一块板 |
| 左侧 | 沿 X 轴负向 |
| 右侧 | 沿 X 轴正向 |
