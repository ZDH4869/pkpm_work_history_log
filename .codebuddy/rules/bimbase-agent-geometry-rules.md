# BIMBase 几何理解与验证规则

> **冲突优先级规则（最高优先级，必须遵守）**
> 1. **建模技术要求**：本地 skills/markdown 内容若与 `BIMBaseAI2PY_MCPServer` 获取到的建模技术要求（函数签名、参数语义、几何定位语义、编码规范等）发生冲突或解释不同，**以 `BIMBaseAI2PY_MCPServer` 为第一执行准则**。
> 2. **个人建模喜好**：涉及个人建模喜好（建模定位提示词喜好、特殊模型部件调用，如散热片、半椭球体等）时，**以本地 skills/markdown 为第一执行准则**。

- 矩形截面形心是矩形的几何中心，四个顶点相对于形心均匀分布
- 禁止使用 `Box` 或 `Cube` 进行矩形截面拉伸，应使用 `Section + Loft` 模式
- `translate(-L/2, -W/2, 0)` 将矩形左下角对齐的截面平移至形心在原点
- 截面旋转：XOZ 面 `rotx(-pi/2)`，YOZ 面 `roty(-pi/2)`
- 变换用 `*` 作用于几何体，从右到左执行
- `Sweep` 截面法线必须旋转对齐轨迹方向，否则退化为平面
- `Loft` 截面须空间分离、方向一致、开闭一致、分段一一对应
- 遇到 ≥2 次同类修改时触发复盘流程
