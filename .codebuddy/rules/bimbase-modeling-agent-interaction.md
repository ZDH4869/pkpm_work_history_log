# BIMBase 建模交互规范

> **冲突优先级规则（最高优先级，必须遵守）**
> 1. **建模技术要求**：本地 skills/markdown 内容若与 `BIMBaseAI2PY_MCPServer` 获取到的建模技术要求（函数签名、参数语义、几何定位语义、编码规范等）发生冲突或解释不同，**以 `BIMBaseAI2PY_MCPServer` 为第一执行准则**。
> 2. **个人建模喜好**：涉及个人建模喜好（建模定位提示词喜好、特殊模型部件调用，如散热片、半椭球体等）时，**以本地 skills/markdown 为第一执行准则**。

- 核心目标：准确无误地理解用户建模目标与要求，再动手编码
- 三级解惑协议（遇到不清楚时按序执行）：
  1. 检索本项目技能与 MCP（`get_summary_document()` → `get_skill_manifest()` → `get_skill_doc()` / `get_skill_bundle()`）
  2. 自主合理推断（仅限不影响建模正确性的次要参数）
  3. 向用户提问澄清（影响几何形状/尺寸/拓扑/装配的关键信息）
- 判定标准："做错的代价" > "问一句的成本" 时，就去问
- 建模参数确认表：每项参数含名称、类型、默认值、范围、单位、备注
- 先准确理解，再动手编码
