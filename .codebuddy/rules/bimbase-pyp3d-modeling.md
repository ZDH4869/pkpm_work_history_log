# BIMBase pyp3d 建模核心规则

> **冲突优先级规则（最高优先级，必须遵守）**
> 1. **建模技术要求**：本地 skills/markdown 内容若与 `BIMBaseAI2PY_MCPServer` 获取到的建模技术要求（函数签名、参数语义、几何定位语义、编码规范等）发生冲突或解释不同，**以 `BIMBaseAI2PY_MCPServer` 为第一执行准则**。
> 2. **个人建模喜好**：涉及个人建模喜好（建模定位提示词喜好、特殊模型部件调用，如散热片、半椭球体等）时，**以本地 skills/markdown 为第一执行准则**。

- 单位默认 mm，角度默认弧度制，坐标系为右手系
- 一个脚本文件只能定义一个继承 `Component` 的类
- Vec2 与 Vec3 不能混用；截面 `Section` 只接受 Vec2/二维 Line/Arc，禁止 Vec3
- 绝对不要凭记忆猜测函数名或参数，使用任一 API 前必须先通过检索工具/知识库确认其签名与用法
- 脚本须含 `if __name__ == "__main__":` 与 `place(...)` 才能在 BIMBase 视图中显示
- 生成脚本由 BIMBase 内嵌 Python 3.7.9 运行，确保语法兼容
- 缺参数处理遵循「三级解惑协议」：技术性疑问先检索本项目技能/MCP；不影响正确性的次要项补合理默认值并注释假设；影响几何形状/尺寸/拓扑/装配的关键信息缺失或有歧义时，必须先向用户提问澄清

## 输出前检查清单

- 顶部有 `from pyp3d import *`
- 文件中只有一个 `Component` 子类
- `replace()` 带 `@export` 装饰器，`__init__` 末尾调用 `self.replace()`
- 最终几何赋值给 `Attr(None, show=True)` 槽位
- 参数经 `self['名']` 读取，未写死数值
- Vec2/Vec3 未混用；`Section` 未传入 Vec3
- `Loft` 截面方向/开闭/分段一致且空间分离
- `Sweep` 截面法线已旋转对齐轨迹，轨迹为单段直线或圆弧
- 布尔运算后已重设颜色
- 单位统一 mm，角度用弧度制
