# 螺钉 & 扭面建模方法分析

---

## 一、核心方法：Section + Loft 的组合范式

两个模型均采用 **"Section 定义截面 + Loft 放样连接"** 的范式，而非 Sweep 扫掠。

| 对比维度 | Sweep | **Loft（本项目采用）** |
|----------|-------|----------------------|
| 截面数量 | 1 个截面，沿轨道重复 | **多截面**，每个独立定义 |
| 适用场景 | 等截面沿路径扫掠 | **变截面渐变 / 螺旋多姿态** |
| 截面变换 | 路径切线自动对齐 | **手动控制每截面的位姿** |

**结论：Loft 是基准方法。** Section 负责定义截面形状，Loft 负责将多个截面连接为实体。

## 二、螺钉模型：严丝合缝的螺纹构建

### 2.1 问题本质

螺纹是**同一三角形截面以不同姿态（旋转+抬升）螺旋排列**后放样。关键是每个截面之间衔接无误。

### 2.2 截面定义

```python
section = rotate(Vec3(1, 0, 0), 0.5 * pi) * Section(
    Vec2(R + height, 0),        # 齿尖（径向最外端）
    Vec2(R, -base / 2.0),       # 齿底（芯柱表面，轴向下方）
    Vec2(R, base / 2.0)         # 齿底（芯柱表面，轴向上方）
)
```

**步骤拆解：**

1. **在 XY 平面定义三角形** (`Section(Vec2(...))`)
   - 三个点构成闭合三角形（Section 自动闭合回起点）
   - X 轴 = 径向，Y 轴 = 轴向

2. **旋转 90° 到 XZ 平面** (`rotate(Vec3(1,0,0), 90°)`)
   - 将 XY 平面截面翻转到 XZ 平面
   - 此时 X = 径向，Z = 轴向

3. **截面不包含平移**
   - 齿底已经在 X = R（芯柱半径）处，无需额外 `translate`
   - 齿尖在 X = R + height 处

### 2.3 螺旋阵列生成

```python
total_angle = N_threads * 2.0 * pi      # 10 圈 = 20π 弧度
z_per_rad = pitch / (2.0 * pi)           # 每弧度的 Z 升高量
step_angle = 2.0 * pi / N_per_turn       # 每步角度增量

for angle in linspace(0, total_angle, 360):
    z = z_per_rad * angle
    positioned = translate(0, 0, z) * (rotz(angle) * section)
    sections.append(positioned)
```

**变换链（从内到外）：**

```
section（XZ 平面三角形）
    ↓ rotz(angle)：绕 Z 轴旋转，使截面朝向不同方位角
    ↓ translate(0, 0, z)：沿 Z 轴抬升到对应高度
    → 最终截面姿态
```

### 2.4 严丝合缝原理

```
截面 N                          截面 N+1
  齿尖                               齿尖
   /\                                /\
  /  \          Loft 连接           /  \
 /____\    ─────────────────→      /____\
齿底 齿底                        齿底 齿底
  ↕ 底边长度 = 螺距                 ↕ 底边长度 = 螺距
```

| 保证条件 | 实现方式 |
|----------|----------|
| **截面数量一致** | 所有截面均为 3 段闭合三角形，`linspace` 均匀生成 360 个 |
| **顶点顺序一致** | 每个截面顶点按相同顺序（齿尖→齿底1→齿底2），Loft 按序对应连接 |
| **方向一致** | 所有截面绕 Z 旋转 + Z 抬升，旋转方向相同 |
| **间距匹配** | `z_per_rad * step_angle` = 每步抬升量，累积后每圈恰好升高一个螺距 |
| **齿底对齐芯柱** | 齿底始终在 X=R（芯柱半径），Loft 连接后齿底曲面 = 芯柱圆柱面 |
| **smooth=True** | 对 360 个截面的 Loft 启用平滑，消除多边形棱角 |

### 2.5 数据流全景

```
Arc(圆形截面)   →   scale(椭圆)    →   translate(z) + rotz(θ)  →  Loft → 塔身
                                                        ↓
Loft 不做截面间插值变形，只做曲面连接。每一个截面姿态完全由我们控制。
```

## 三、扭面模型：不同截面的渐变扫掠

### 3.1 问题本质

从矩形截面渐变到平行四边形截面，连接处需自然过渡。

### 3.2 两截面定义

```python
# 初始截面：矩形 (z=0)
section_start = Section(
    Vec2(0, 0), Vec2(W, 0), Vec2(W, H), Vec2(0, H)
)

# 最终截面：平行四边形 (z=L)，底部重合、顶部偏移
dx = H * tan(tilt)
section_end = Section(
    Vec2(0, 0), Vec2(W, 0), Vec2(W+dx, H), Vec2(dx, H)
)
```

**关键约束：截面结构必须匹配**

| 约束项 | 初始截面 | 最终截面 | 是否匹配 |
|--------|----------|----------|----------|
| 线段数 | 4 | 4 | ✓ |
| 闭合性 | 闭合 | 闭合 | ✓ |
| 顶点顺序 | 逆时针 | 逆时针 | ✓ |
| 线段类型 | 全部 Line | 全部 Line | ✓ |

- **线段数不一致会报错**
- **存在 Arc 混入会导致放样失败**
- **方向相反会产生自交**

### 3.3 渐变扫掠实现

```python
Loft(section_start, translate(0, 0, L) * section_end)
```

只需两个截面，Loft 自动完成中间的线性渐变：

```
z=0:    (0,H)──(W,H)          z=L:  (dx,H)──(W+dx,H)
          │      │                    ╱        ╱
          │ 矩形 │         Loft       ╱ 平行四 ╱
          │      │      ==========>   ╱  边形  ╱
       (0,0)──(W,0)              (0,0)──(W,0)
       
      底部重合不动              底部同样重合
      顶部保持直线              顶部向右偏移 dx
```

Loft 在连接时对每条对应边做线性插值：

- **底边**：两端都是 `(0,0)→(W,0)`，无变化 → 形成平直底面
- **顶边**：从 `(0,H)→(W,H)` 渐变到 `(dx,H)→(W+dx,H)` → 形成渐变倾斜顶面
- **左右侧边**：从竖直渐变到倾斜 30° → 形成扭转侧面

### 3.4 为什么只用 2 个截面就够了？

因为渐变是**线性的**，无需中间截面过渡。Loft 自动对每对对应边做线性插值，中间任意位置的截面自动计算得出。

**与螺钉的对比：**

| | 螺钉 | 扭面 |
|--|------|------|
| 截面数 | 360 个 | 2 个 |
| 原因 | 螺旋路径需要密集采样 | 线性渐变只需端点 |
| 截面形状变化 | 不变（始终三角形） | 变（矩形→平行四边形） |
| 截面姿态变化 | 旋转+抬升（非线性） | 仅平移（线性） |

## 四、建模方法论总结

```
┌─────────────────────────────────────────────┐
│              建模决策树                       │
├─────────────────────────────────────────────┤
│                                             │
│  截面是否沿路径变化？                         │
│     │                                       │
│     ├─ 否 → 等截面扫掠 → 可考虑 Sweep         │
│     │                                       │
│     └─ 是 → Loft                            │
│              │                              │
│              ├─ 线性渐变 → 2 截面即可         │
│              │   （如扭面、长方体→平行四边形） │
│              │                              │
│              └─ 非线性路径 → 密集截面采样     │
│                  （如螺纹螺旋、广州塔扭转）     │
│                                             │
├─────────────────────────────────────────────┤
│            Loft 成功的关键条件                 │
├─────────────────────────────────────────────┤
│  1. 所有截面线段数完全相同                     │
│  2. 所有截面均闭合                           │
│  3. 顶点/线段的顺序方向一致（同为 CCW 或同为 CW）│
│  4. 仅用 Vec2 + Line，不混用 Arc（pyp3d 限制） │
│  5. smooth=True 可消除多边形棱角              │
└─────────────────────────────────────────────┘
```
